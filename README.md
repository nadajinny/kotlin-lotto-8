# kotlin-lotto-precourse

## 로또 발매기 만들기

### 입력

```cookie
구입금액을 입력해 주세요.
8000

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7
```

### 입력에서 발생하는 예외 사항

```
구입 금액이 비어있을 경우
-> "[ERROR] 구입 금액이 제대로 입력되지 않았습니다." 출력 후, 재입력

구입 금액이 숫자로 이뤄져있지 않은 경우
-> "[ERROR] 구입 금액이 잘못 작성되어 있습니다." 출력 후, 재입력

구입 금액이 1000원보다 낮을 경우 
-> "[ERROR] 구입 금액이 1000원보다 적습니다." 출력 후, 재입력

구입 금액이 1000으로 나누어떨어지지 않을 경우
-> 1000으로 나누었을 때의 값만 로또를 발행한다. (나머지 금액은 무시)

당첨 번호를 6개 미만 혹은 초과할 경우
-> "[ERROR] 당첨 번호가 6개가 아닙니다." 출력 후, 재입력

당첨 번호가 중복될 경우
-> "[ERROR] 중복된 당첨 번호가 있습니다." 출력 후, 재입력

당첨 번호가 입력되지 않았을 경우
-> "[ERROR] 당첨 번호가 입력되지 않았습니다." 출력 후, 재입력

당첨 번호가 1과 45 사이의 숫자가 아닐 경우
-> "[ERROR] 당첨 번호가 1~45 사이의 숫자가 아닙니다." 출력 후, 재입력

보너스 번호가 당첨 번호와 중복될 경우 
-> "[ERROR] 보너스 번호가 당첨 번호와 중복됩니다." 출력 후, 재입력

보너스 번호가 입력되지 않았을 경우
-> "[ERROR] 보너스 번호가 제대로 입력되지 않았습니다." 출력 후, 재입력
```

### 구현해야하는 기능 목록
- [x] 로또 구입 금액 입력받기
    - [x] 로또 구입 금액 조건 확인
- [x] 로또 당첨 번호 입력받기
  - [x] 로또 당첨 번호 조건 확인
- [x] 로또 보너스 번호 입력받기
  - [x] 로또 보너스 번호 조건 확인
- [x] 로또 구입 갯수에 맞춰서 로또 발행
- [x] 로또 당첨 여부 확인하기
- [x] 로또 당첨 출력
  - [x] 각 랭크별 당첨 여부 출력
  - [x] 총 수익률 출력

### 조건
- 당첨 조건
    - 1등: 6개 번호 일치 / 2,000,000,000원
    - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
    - 3등: 5개 번호 일치 / 1,500,000원
    - 4등: 4개 번호 일치 / 50,000원
    - 5등: 3개 번호 일치 / 5,000원
- 로또 개당 금액 = 1000원

### 프로그래밍 요구 사항
- 프로그램 실행의 시작점은 Application의 main()이다.
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
- else를 지양한다.
- Enum 클래스를 적용하여 프로그램을 구현한다.
- Lotto에 numbers 이외의 필드(인스턴스 변수)를 추가할 수 없다.
